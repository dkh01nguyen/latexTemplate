This page is used to quick described how to use the template.
\begin{itemize}
    \item Folder \texttt{content}: contains modules, a.k.a parts of the report. 
        You can find the \code{coverpage.tex} file here to modify the coverpage. The \code{members.tex} file
        should be a solid framework for each and every tables in your article. Headers and footers is modifiable via 
        \code{main.tex}, as well as libraries and other elements.
    \item Folder \texttt{picture}: contains pictures in your paper. It is not something too flashy, just a 
    more convenient and simplier way to store your images. Access through \texttt{picture/your\_picture\_name\_here} when you're
    writing.
\end{itemize}
